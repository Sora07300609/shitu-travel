# 拾途 · 城市旅行网站

完整静态网站源码，HTML、CSS、JavaScript 集中在 index.html。无需构建或安装依赖。

## 本地运行

在目录中运行 `python3 -m http.server 8080`，然后在浏览器打开 http://localhost:8080 。

## 功能

城市选择、目的地与美食标签备忘录、默认五天行程、分时段目的地和三餐、行程与三餐对齐共同滚动、真实地图、地点查询和手动放置、选择两个地图端点后弹窗记录交通方式与分钟数。

各城市记录保存在浏览器 localStorage。本源码包不包含浏览器中已保存的个人行程。

## 地图与网络

Leaflet、OpenStreetMap 地图瓦片与 Photon 地点查询需要联网。部分网络环境可能无法连接；源码中已保留错误提示和手动标点。景点和地方风味为预置参考，非实时热榜。
