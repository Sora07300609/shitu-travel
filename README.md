# 拾途 · 旅行规划网站

旅行日历、全球地图、每日景点与美食、照片文字记载、消费统计。静态网站，无需构建，完整页面代码位于 `index.html`。

## 本地运行

```bash
python3 start-preview.py
```

保持终端开启，在浏览器打开 http://127.0.0.1:8765/ 。macOS 也可在终端运行 `zsh 启动拾途.command`。请通过网页地址访问，不要把 GitHub 的源码展示页当作网站。

## 当前功能

- 日历中点击起止日期选中旅行区间，可添加多段。“重新选择”逐次撤销最新区间。
- 点击已选日期或全球地图上的着色省份，打开同一个行程弹框：第一页是整趟总览，翻页查看每日安排，也可用小日历切换。
- 每天可选择城市，景点和美食默认各五行，可增减。第一次点击选择候选词条，第二次点击自主输入，新增内容自动同步到城市词条库。
- 全球平面地图支持拖动、双指平移和光标位置缩放。放大逐步显示省、市和景点；文字优先显示行程内容并避让重叠。
- 省份按旅行日期与城市着色，显示旅行时间；底图低饱和，仅景点标记使用高饱和颜色。国内市级边界已内置，无道路底图。
- 景点小点打开文字与照片的缩略浮窗，再点击展开完整记录。每日附件中的 `【景点名】` 文字、含景点名的照片批注会关联相应景点。
- 每日一个附件，支持文字、照片叠放、展开、预览、删除及逐张批注。
- 总览地图聚焦所选城市；每日地图聚焦当天景点。地图支持触控板平移与捏合缩放。
- 每日消费自动汇总到总消费统计；机票、住宿在共享消费区记录。必带物品属于整趟旅行。
- 美食不在地图上标记。已填写但尚无坐标的景点保留“待定位”提示，不会伪造位置。

## 数据保存与联网需求

行程、词条和消费保存在当前浏览器、当前网站地址的 localStorage；照片保存在 IndexedDB。本仓库不包含用户行程、消费记录或照片，也不提供跨设备同步。更换域名、端口或浏览器会使用不同的本地存储。

全球地图轮廓、国内省市边界和全球主要城市名称内置在页面中。弹框地图使用 Leaflet，加载组件需要联网；其他城市的区县细节可按需联网加载，广州区界已内置。地点坐标自动查询使用 Photon，查询失败时可在每日地图手动放置刚填写的景点。

底图数据来源：

- [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/)：世界轮廓及主要城市。
- [阿里云 DataV GeoAtlas](https://datav.aliyun.com/portal/school/atlas/area_selector)：国内行政区边界。
- [Leaflet](https://leafletjs.com/)：弹框地图交互。

行政区轮廓为可视化用途，经过精度简化；景点连线表示游览顺序，不是道路导航。预置词条不是实时热榜。
