# 拾途 · 旅行规划网站

静态网站，完整 HTML、CSS、JavaScript 位于 `index.html`，无需构建。

## 本地运行

```bash
python3 -m http.server 8080
```

在浏览器打开 http://localhost:8080 。地图与地点搜索需要联网。

## 当前功能

- 日历置顶，直接点击未选日期的起点和终点来添加旅行区间；多段可累计，空档分段标色，日序号分别从第1天开始。
- “重新选择”每次撤销最近添加的一段日期。
- 左键单击标色日期展开下方旅行信息；右键单击标色日期打开当天安排。
- 日期弹框通过左上角小日历选择其他旅行日期；小日历就地展开，没有额外遮罩。
- 每天可指定城市，多城市以词条添加、切换、移除，保留归档内容供恢复。
- 每个城市独立包含目的地、目的地地图、美食；目的地词条自动尝试匹配位置，美食不标记。
- 每日景点、美食默认各5行，可增减；输入框第一次点击选上方未使用词条，第二次点击自主输入。新词自动加入上方并去重，已安排的词条仅在候选列表隐藏。
- 每天统一一个附件，顶部词条可插入备注；照片默认叠放，支持展开、预览、删除、逐张批注。
- 必带物品、预算、消费统计属于整趟旅行。预算词条可增删，单独记录，不计入消费。
- 每日消费自动汇总到共享消费统计。机票与住宿在共享消费区统一记录，旧数据迁移保留。
- 日期弹框地图支持当天与旅行总览。

## 本地数据与地图

行程等数据保存在当前浏览器的 localStorage，照片保存在 IndexedDB。本仓库不包含用户实际保存的行程、消费或照片，不提供跨设备同步。

地图使用 Leaflet / OpenStreetMap，地点查询使用 Photon 公共服务。网络受限或匹配失败时，可能无法显示地图或自动标点；每日地图保留手动放置地点的能力。预置景点、美食为参考词条，不是实时热榜。
